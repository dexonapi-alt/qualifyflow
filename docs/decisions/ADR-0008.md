# ADR-0008 — Sidebar-only typography and account composition

Accepted 2026-11-17 for the explicit sidebar refinement. Preserve the current main workspace, Overview, tabs, canonical palette and business behavior.

Use a sidebar-specific typography-led QualifyFlow wordmark with a quiet cobalt terminal, without the separate blue tile. The existing default Brand remains unchanged on authentication surfaces. Keep the established rail width so main content does not reflow.

Compose brand/divider, a single structural Workspace navigation caption and compact working destination rows. This does not restore the earlier redundant Company workspace / Client account descriptions. Remove the decorative loaded-company count from sidebar navigation; the directory still reports actual loaded records. No unfinished destinations or duplicated company tabs are added.

Account identity comes from the authenticated email and platform role, not an invented display name. Initials are derived from the email. Wrap rather than truncate the address; long addresses use full footer width, while the complete value remains in the working account disclosure. Keep real sign-out, keyboard behavior and compact local/synthetic safety information. On phone, retain the current reachable Account disclosure.

Use existing typography, colors, 1.5-stroke icon conventions and reduced-motion timing. No dependency, backend, API, permission, authentication or M2 work is authorized by this visual change.
