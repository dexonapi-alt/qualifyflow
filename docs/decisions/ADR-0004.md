# ADR-0004 — White working surfaces and action hierarchy

Accepted 2026-11-17. The product owner's final visual-direction correction supersedes ADR-0003's broad lavender workspace and separate account-context/access panels. Original specifications remain unchanged; this aligns with Document 02's white-first operational instrument and functional density.

Use white navigation/header/working surfaces, a barely neutral #FAFBFC surrounding canvas and charcoal #181C25 ink. Cobalt identifies primary actions, active navigation and selected tabs. Lavender-named legacy aliases remain compatible but now resolve to light neutral/blue support values; they do not justify broad colored panels. Semantic amber/red/green communicate actual account state with text.

The single-company overview becomes one coherent record: identity plus configuration/user actions, compact setup notice, inline metadata, ruled details/locations and a small access-scope footer. Manage users is the primary authorized action; Manage locations and View configuration remain actual navigation to working M1 sections. No new API, permission, backend workflow or placeholder is introduced. Detailed readiness remains service-admin-only.

Type hierarchy uses 600 for work/record/section anchors, 500 for controls and primary row values, 400 for ordinary content/metadata. Existing self-hosted Inter and 1.5-stroke utility icons remain. Geometry is supporting detail: 7px controls and 10px record boundaries, minimal elevation. No blue presentation backdrop or borrowed branding.

This decision changes derivative design guidance only. Earlier reports and galleries are historical comparisons. M2 remains the next engineering milestone.
