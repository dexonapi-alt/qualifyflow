# ADR-0027: Reviewed spreadsheet intake and immutable corrections

Date: 2026-11-19. Status: accepted for local synthetic implementation.

The owner authorized continuing the remaining milestone work after the driver portal. This slice extends M3; it does not declare M3–M6 or production readiness complete. Original numbered specifications remain unchanged.

Client handoffs may use different column names or native XLSX. A bounded adapter translates a user-confirmed column map into the existing five-field metadata receipt. The encrypted original bytes, worksheet, headers, map, SHA-256 and mapping version are retained separately from immutable normalized rows. The existing canonical CSV/provider contract remains compatible.

XLSX has a 256 KB compressed / 2 MB expanded archive limit, 128 archive entries, five worksheets, 32 columns and 100 data rows per selected sheet. CSV remains UTF-8, 64 KB, 100 rows. Real antivirus must clear XLSX before XML/Office parsing. Hardened XML parsing rejects formulas and external relationships; macros, embedded files, encrypted archives and legacy XLS are rejected. Numeric identifiers require text or explicit zero-padding; dates are ISO text or actual Excel date cells. No value/category inference, macros or formulas execute. Parser dependencies are openpyxl and defusedxml, pinned in the lockfile. See the [openpyxl security guidance](https://openpyxl.readthedocs.io/en/stable/).

New mapped/corrected receipts require an explicit persisted driver/engagement match before source-linked evidence processing. Current tenant/branch authorization, stable references, typed verification, optimistic driver/engagement versions, actor and encrypted basis are recorded. Names are lookup aids only. Existing evidence validation, real malware scan and authorized review still determine evidence outcomes.

Correction creates a linked, one-row replacement receipt with rationale. The original file and row never change. Duplicate rows cannot be relabeled to bypass deduplication. Used/matched rows are locked. Parent/child uniqueness, command replay hashes, tenant locking and append-only database triggers protect lineage. Ten ancestry versions and 100 mapped imports/company are deliberate local synthetic bounds. Superseded rows cannot open a file or accept new source evidence. Workers skip them; existing related cases gain an event/version change rather than being silently closed. Reviewer resolution and approval gates remain.

Error CSV exports are scope-checked, audited, private/no-store and neutralize spreadsheet formula prefixes. They contain only existing metadata outcomes. There is no real external delivery or original-workbook download.

Deferred: reusable mapping templates, arbitrary transformations/report-type vocabularies, bulk correction, reassignment after match/use, large asynchronous workbook parsing, automated missing-driver creation, production quotas/retention and full M3 exit evidence. The fixed CSV path intentionally retains its previous matching contract for compatibility.
