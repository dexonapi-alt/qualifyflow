# ADR-0015 — Specialist workflow, module navigation and evidence boundary

2026-11-17. Owner identified duplicated company tabs/sidebar destinations and an unintuitive, incomplete workflow relative to the Compliance Data Specialist role. Prioritize usable client → driver/requirement → evidence → review → follow-up paths over new milestone labels. Existing M2/M3/M4 gaps remain open.

Operational destinations belong in primary navigation and have their own title/context. Company sections contain administration only; do not duplicate Drivers/Intake/Exceptions/Approvals as company tabs. Keep selected company visible and persist navigable context without putting driver names or report contents in URLs. Only working routes with actual grants appear.

Introduce versioned operational requirement definitions, per-engagement instances, immutable encrypted evidence objects and append-only review decisions. Stable tenant/driver/engagement/requirement references must agree. No name-only attachment. Review records category, identity, completeness, reviewer and explicit dates. An accepted evidence review is administrative, not legal qualification. Regulatory applicability remains unverified; no rule or renewal duration is invented.

Local environment has no Docker/MinIO executable. For synthetic local development, use a private encrypted filesystem object adapter behind the backend, with random object keys, atomic creation and no static serving. This is a local development equivalent, not production S3 readiness. S3 adapter/operations remain tracked. The same evidence service must not depend on a public file path.

Scanner adapters use actual Microsoft Defender custom scans on this Windows environment, or ClamAV INSTREAM where configured. No simulated successful scan. Scanner failure/unavailability keeps evidence quarantined and unavailable for review/download. Scan process returns only bounded error codes and records scanner identity; no source contents in logs. Downloads require current backend authorization and audit; no public object URLs. All data remains synthetic until separate release/privacy gates.

Testing was stopped by the owner's prior instruction. A question about resuming targeted verification is pending; absent a response, new work remains unverified. No production/team-readiness assertion without executed exit evidence.
