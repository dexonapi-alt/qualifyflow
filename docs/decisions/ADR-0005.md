# ADR-0005 — Unified shell and sidebar account controls

Accepted 2026-11-17 for the precise composition correction. The owner's explicit direction removes the standalone top app bar proposed in Document 02 §6.1. This is a visual composition exception, not a change to product architecture or authorization. Original specifications remain untouched.

Main content begins with the page title, optional useful context, then a smaller breadcrumb and existing section navigation/content. Operations/client identity is retained in the breadcrumb. Selected-company breadcrumbs provide the real return-to-directory action. No blank header strip or parallel branding/context region remains.

The sidebar contains brand, divider, working navigation, compact local/synthetic indicator and account disclosure. Remove redundant workspace/client-account/group labels. Active navigation uses a quiet neutral surface rather than primary-action styling. A single company needs no decorative switcher; multiple authorized companies remain reachable through the existing company directory.

Move the identical logout API operation into the account disclosure. Native summary keyboard behavior, Tab to sign-out, Escape close/focus return and narrow-screen account access are supported. Verify actual session invalidation, not just a change to the displayed screen. No unsupported profile settings are introduced.

The main canvas is continuous white. Remove the single-company outer frame and redundant footer/environment copy, retaining internal rules, content-driven sections, existing actions and state messages. Do not change fonts/palette, add imagery or invent modules. Preserve the current M1 workflows and M2 as next.
