# ADR-0002 — Synthetic local identity and asynchronous delivery
Accepted for local/test only; runtime refuses other environments.

Maintained Argon2 password hashing and PyOTP TOTP; encrypt seeds with environment-managed Fernet key. Random opaque sessions persisted only as hashes, bounded lifetime, HttpOnly SameSite cookies, CSRF header and origin validation. Current user/grants checked every call. Privileged roles require MFA. Explicit local bootstrap CLI, no public registration. Invitations expire, are tenant-bound/single-use/hashed. Existing-user acceptance requires authenticated matching account, preventing password takeover.

Only local Mailpit SMTP permitted initially. Invitation + encrypted outbox token + audit commit atomically. Worker delivers fragment invitation URL; token never appears in admin API/logs or HTTP path. SMTP acceptance is sent, never proof of delivery/read. Durable outbox retains failures/retries.

Production IdP/recovery, distributed abuse controls, managed vault, TLS, role/access review, restore and security release gates remain open. Local MinIO reserves private storage for M2; no document access until quarantine/scanning tests exist.

Live rerun clarification: use FastAPI function-scoped database yield dependencies (minimum FastAPI 0.121) so transaction finalization commits before an HTTP response is sent. Request-scoped teardown allowed a subsequent live request to reach an uncommitted session. A commit-failure regression must return a safe error rather than a success response; live demo account checks verify immediate authenticated reads.
