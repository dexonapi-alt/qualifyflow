# ADR-0003 — Balanced operational surfaces

Accepted 2026-11-17 for the user-authorized premium visual overhaul before M2.

Document 02 remains the creative specification. The latest product-owner direction explicitly permits purposeful cards and asks for cool-neutral/lavender surroundings, white task surfaces and softer component proportions. This supersedes the preceding derivative design rules that prohibited colored status surfaces or required an entirely open single-company record. Original specifications are unchanged.

Use a cool near-white workspace, a slightly deeper navigation surface, white information/editing panels and two restrained supporting surfaces: lavender for account context, blue-gray for access context. Cobalt continues to identify brand, primary actions, focus and selected tabs. Operational state colors keep separate semantic meaning. No decorative metrics, fake setup percentages, invented activity or future navigation.

Retain licensed self-hosted Inter, the existing 24-unit/1.5-stroke utility family, native forms and current data flow. Company summary facts come from persisted company/membership data. Setup messaging names the existing service-administrator activation responsibility; it does not infer qualification or legal eligibility. The account disclosure exposes existing identity information with native keyboard behavior.

Canonical values stay in design-system/qualifyflow/tokens.css. frontend/src/premium.css is the current shared composition/component layer; frontend/src/style.css retains base behavior/responsive rules. The previous craft override block was removed instead of adding a third competing refinement layer. No backend service, API contract, authorization, migration or authentication change is part of this decision.

Tradeoff: explicit information groups introduce more surfaces than the previous iteration. Every current panel has one task boundary, and directory/audit/member rows remain lists rather than dashboard tiles. Future pagination, context menus and bulk actions require real backing workflows; their visual guidelines do not authorize disconnected controls.
