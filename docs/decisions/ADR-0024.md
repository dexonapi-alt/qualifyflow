# ADR-0024 — Automatic return through invisible profile regions

2026-11-19. Owner removes the visible X and requests pointer-driven return: keep the card centered while the cursor is over the centered card or its reserved original footprint; return when it leaves both. This refines ADR0023, preserving its Motion translation/scale, full-opacity content and blur-only backdrop.

The original footprint remains in layout and is measured as a noninteractive geometric hover region. A small edge allowance and convex travel corridor connect it to the centered frame. Leaving schedules a150ms return grace; moving back cancels it. Reentry during the240ms automatic return reverses smoothly to center. Explicit Escape or backdrop dismissal is not reversed by hover. Clicking the invisible original region does not dismiss the view or activate background controls.

Mouse hover and mouse Expand use automatic return. Keyboard/touch entry retains deliberate dismissal; keyboard interaction disables pointer dismissal so a parked cursor cannot interrupt focus. Escape and tap outside remain available. The visible X is removed; an accessible Return action appears only when keyboard-focused. Automatic return restores the previous focus context rather than trapping focus in the source, allowing repeated hover cycles. Explicit dismissal restores the Expand control.

No backend/API/security or data changes. Pure geometric tests cover source/center/corridor/edge retention and outside rejection; actual browser tests cover retention, return, reversal, repeated hover, keyboard, touch and file navigation. Existing Motion chunk-size warning remains recorded; this refinement does not claim production performance certification.
