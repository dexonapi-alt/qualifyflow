# ADR-0020 — Scoped configured-evidence reporting and private exports

2026-11-18. Begin the reporting part of M6 without asserting operational or commercial release readiness. Reports describe current employer engagements and requirements actually assigned by the client. A verified evidence state never means a statutory qualification decision. Drivers with no assigned requirement are not silently counted as complete.

Current reviewer/client-administrator capability governs reports and exports; provisioning authority never implies report access. Every report query retains tenant and current branch scope. Export generation and download independently recheck current actor, authority, tenant state and the original scope. A changed scope fails closed. Exports are private to their requesting user; there are no public links or bearer download URLs.

PostgreSQL owns durable export requests and encrypted CSV snapshots. Generation runs atomically under tenant/job locks, so a failed transaction can be retried without partially publishing a file. Requests are idempotent by actor/tenant/command and exact purpose. Downloads verify the recorded content hash, force attachment delivery and disallow caching. CSV cells neutralize spreadsheet formulas. Ten requests per actor/hour and 1000 assigned requirements per local report are explicit limits; exceeding the report cap fails rather than silently omitting data.

Export contents expire after one hour; the worker clears the encrypted snapshot while preserving request metadata and append-only audits. This short-lived export policy does not delete source evidence or establish production retention rules. Legal holds, privacy/offboarding workflows, production storage, scoped machine APIs, independent security/compliance reviews and restore/load drills remain separate deliverables.
