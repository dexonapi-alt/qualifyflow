# ADR-0007 — Correct the Overview summary regression

Accepted 2026-11-17. Supersedes only the 2×2 metadata-card recommendation in ADR-0006, explicitly rejected by the product owner. Preserve its shared working navigation, operational tables and authorization decisions.

Overview is an open, proportional 7/5 desktop composition: Company information and Setup & access. Ordinary values are plain text. Remove summary rectangles and nested input-looking value boxes. Show the exact account state once in the compact company identity; activation context is descriptive text, not another Draft pill. A single soft role badge communicates an actual category. Place authorized management actions within Setup & access, where they remain discoverable without a bottom-of-page action block. Stack sections naturally on narrow screens.

Do not alter the sidebar, page title/breadcrumb/tabs, font family, palette or backend to correct this composition. Do not reset repository history or fill available space with invented data. Keep actual management tables and real handlers.

Audit actor/target identifiers already exist in the authorized audit API response. Render them with timestamps/events and expandable full identifiers; no actor names or targets are invented and no endpoint contract changes. Company and account metadata stay within the existing returned scope.

Stop after this focused correction and verification. M2 is not started.
