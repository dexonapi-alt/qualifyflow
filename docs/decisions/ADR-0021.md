# ADR-0021 — Personal driver profile and evidence checklist

2026-11-19. The owner requests a more personal driver onboarding experience, inspired by the supplied onboarding/identity image and `this design.jpg`. Both references were visually inspected. Extend the existing driver record, preserving the application shell, current typography/color foundations and backend contracts.

Replace the text-row Record overview with **Driver profile**: a bounded personal identity panel, current employer engagement, actionable evidence checklist and permission-scoped recent record activity. Use generated initials because the product has no supported driver-photo upload workflow. A driver remains the subject of a private company record, not a new login/social account.

The checklist uses existing authorized qualification-file data for the current engagement only. The progress denominator is actual assigned requirements; the numerator is requirements whose evidence state is verified. Label the measure explicitly, never as legal eligibility or overall onboarding completion. Zero assignments shows an actionable starting state, not a fabricated percentage. Awaiting review does not assert an active human reviewer. Do not invent due dates, owners, photos, or completed tasks.

Native disclosures reveal details; View requirement opens the existing file and focuses the exact requirement heading. Completion remains controlled by the real scan/review workflow. The profile's Refresh action reloads both identity/history and requirement data. Viewer roles do not request evidence data or receive edit/file/history controls without their existing capabilities. Source-linked file entry still opens the file directly, preserving intake context.

Design: restrained mint identity cover, blue initials/primary action/progress, pink pending and green awaiting-review recognition cues, readable textual state labels, 18px main radii and a24px desktop column rhythm. White canvas, Inter and shared icons remain. This is a focused driver-page extension, not another platform redesign.
