# ADR-0010 — Action-led three-module Company Overview

Accepted 2026-11-17 after the owner explicitly approved the recommended company profile/readiness/locations composition. Supersedes ADR-0007's open-column requirement only for Overview. Preserve its rejection of four generic metadata cards and input-looking value bubbles. ADR-0008 sidebar and ADR-0009 truthful visual information remain.

Overview uses one larger company-profile card beside separate readiness and location modules. Identity/status moves inside the profile for clients; other tabs retain the compact identity header. Operations retains its existing company page heading/status and uses Company profile as the module heading, avoiding competing duplicate company headings.

Profile groups Organization, Primary contact and Service details; ordinary values remain plain text with labels above. Readiness holds state, actual role/scope and authorized next actions. Locations previews at most two returned authorized branches with actual state and stable references, explicitly labels its scoped count, and opens the complete existing location section. Empty states never fabricate records or progress.

The same existing detail response and current permissions drive every module. No new backend read/write, schema, workflow, security policy, dependency, font, sidebar or unrelated screen change. Responsive order is profile, readiness, locations. Existing reduced-motion timing and keyboard behavior apply. M2 remains paused pending review.
