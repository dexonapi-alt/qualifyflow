# ADR-0022 — Intent-driven interaction emphasis

2026-11-19. The owner explicitly requests hover enlargement and minimal background blur for the driver profile, plus a coherent interaction strategy elsewhere. Extend Evidence in Motion without changing application architecture or working flows.

Use a1.018 scale/3px lift and soft elevation for the identity card on fine-pointer desktop at1024px and above. Adjacent profile context receives at most0.65px blur after70ms hover intent. Navigation/header/dialogs are never part of the blurred layer. No overlays, pointer blocking, delayed actions or persistent GPU hints are introduced.

Focused controls and expanded requirement details suppress contextual blur. Keyboard users receive an identity-group focus border, without spatial zoom. Touch and reduced-motion modes omit zoom/blur. CSS alone controls these reversible states; no data operations or mouse-tracking listeners are added.

Elsewhere, use restrained panel borders/elevation, stable row hover/focus highlights, navigation color feedback, small directional action arrows and disclosure hover surfaces. Operational tables keep their geometry and scan order; do not apply cinematic zoom/blur across every page. Preserve existing focus indicators and actual state/permission rules.

New values live in canonical tokens.css; runtime rules are interaction-polish.css. Screenshots and targeted interaction evidence are in docs/design/interaction-polish. This is an interaction refinement, not another visual redesign or milestone completion.
