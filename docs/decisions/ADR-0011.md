# ADR-0011 — Final visual language and confirmed action feedback

Accepted 2026-11-17 for the owner's final pre-M2 polish pass. Keep ADR-0010 Overview composition, sidebar, tabs, fonts, API contracts and authorization.

Extend the existing 24-unit/1.5-stroke utility family with location, service, access-key, pause and information symbols. Use location for a branch record, connected structure for organization relationships, service for operational service details, and access-key for permission context. No new icon dependency or externally hosted asset.

Original spot illustrations use a common record frame, subdued ground, single concept and restrained cobalt detail. Locations, invitations, specialist assignment and no-results states share this family. Decorative SVGs are hidden from assistive technology; adjacent headings, explanations and working controls supply meaning. No illustrations replace operational data or create future-module links.

Identity marks derive initials and deterministic neutral supporting tones from actual record values. Organizations and people remain geometrically distinct. Color does not communicate role/status. Readiness differentiates pending, active, suspended and neutral/unavailable states; unknown is never presented as verified or suspended.

Form confirmation appears beside the completed action only after its existing save and detail refresh resolve. Parent-owned path/message feedback preserves it when section refresh or version changes remount the form. The existing refresh trigger remains separate from the displayed message. Pending/rejected forms suppress success feedback; errors stay actionable and persistent. Existing row actions receive section-level confirmations. No backend workflow or transaction change.

Semantic form headings and compact specialist records bring management screens into the current visual system. Keep native forms, focus/keyboard behavior, real invitation states and reduced-motion support. Original four specs remain unchanged. Stop after verification; M2 awaits review.
