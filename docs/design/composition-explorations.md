# Three task-specific composition explorations
Static layout studies, not implemented feature claims.

## Operations home
```
Assigned clients / persistent context
18 reports need review.             [Open queue]
------------------------------------------------
Ranked work: age | client | reason | owner | action
Failures and blocked items in secondary ruled rows
```
Dominant actionable count; queue is hero, no KPI-card grid.

## Screening intake
```
Screening intake                   [Import records]
Search | client | status | received
------------------------------------------------
Dense source/driver/company/time/state table
Selected source | structured identity comparison
                | anchored permitted review actions
```
Stable rows and context; evidence comparison earns its container, no entrance animation.

## Client portal
```
Company identity / authorized branch scope
Requests needing your action.
------------------------------------------------
Document request | driver reference | due | respond
Approval request | exact action     | due | review
Secondary roster/account access
```
Plain language and larger targets; no specialist internal queue. Current M1 implements company/account administration only; requests arrive with M4.
