# M3/M4 operational workspaces

Preserve the approved Evidence in Motion foundation. The sidebar now has actual company-scoped module destinations rather than hiding all functionality in company settings. A real company label establishes context; no artificial navigation counts or unfinished modules are added. Narrow-screen navigation scrolls without hiding account controls.

Intake remains a compact operational table with source references, explicit row outcomes and a separate processing lifecycle. Exceptions use a scannable queue, generated initials for actual owners, a two-column source/attention context, state-driven controls and a chronological event list. Approvals use distinct review records because proposal, expiry, source context and decision controls need more space than a roster row. Semantic states remain textual as well as colored.

All control visibility comes from real grants/server state; services recheck them. No decorative metrics, invented people, confidence scores, progress percentages or legal eligibility states are introduced. Administrative approval cannot stand in for missing evidence review.

Design QA has not been executed for this slice because the owner stopped tests. No rendered screenshot or responsive/a11y pass is claimed. Preserve the existing typography, icon family, form behavior, reduced-motion CSS and white surfaces. See ADR-0014 and the workspaces runbook for behavior and remaining scope.
